# Manuscript terminology

- MASCOT after the first expansion: Mission, Architecture, Stack, Commands, Operational Overview, Testing.
- Core audience: one engineer directing one agent locally; team/production material is an optional extension.
- One ring. Use the ring or the model after introducing the supplied 3D asset. classic is a technical identifier, not a product nickname.
- Core UI areas: Player, Top, Colors. Team shoulder names identify geometry; no Team editor or logo is included.
- UI labels use visible title case and bold in print: Player name, Number, Position, Reset design, Ring metal, Lettering metal, Top stones, Side stones.
- Commands, paths and identifiers use code styling. type-check names the npm script; type check is the noun.
- First preview is prose; docs/specs/first-preview.md is the path.
- Logo limit: 5 MiB = 5,242,880 bytes. Do not label it 5 MB.
- All app/config/test paths are expected agent outputs or inspection points. Reader authors Markdown and reviews; no manual TS/TSX assignment.
- Verification status: passed, failed, not run. Distinguish automated results from direct observations and identify operator/environment.
- Optional sections can be skipped without breaking a core assignment.
