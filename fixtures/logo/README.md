# Logo input fixtures

logo-shield.png is an original, unbranded geometric shield on a transparent 512 × 512 PNG canvas. It was created for this companion at Sean’s direction from simple drawn shapes. See [creation and provenance](../../provenance/logo-fixture.md). notes.md is an unsupported Markdown file. not-an-image.png deliberately contains invalid image data despite its PNG extension.

After accepting the shield, try the unsupported and corrupt files separately. They should produce distinct file-contract and decode failures while retaining the accepted image. These are input assets, not a test implementation. The agent creates size-boundary, format, resizing and stale-read checks in the reader’s project.

The exercise depends on the accepted image and placement behavior, not a particular symbol or color. No customer artwork is included. No public reuse license is selected by this record.
