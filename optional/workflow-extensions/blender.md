# Optional extension

This material is outside the core Ring Builder path. It grants no tool access or authority. Check current documentation before using it.

Optional Model Work With Blender MCP

The model is enough for the core walkthrough. If you want to explore model preparation separately, Blender MCP offers an optional way for an agent to help in Blender. It is a community integration, separate from the Blender Foundation, whose documented architecture connects an MCP server to a Blender add-on and can execute Python in Blender. Read the maintainer's current instructions for your client and review the access and files it can affect before enabling it.

Keep that exploration in a separate assignment using a copy of the source scene and a visual inspection of the output. The companion’s optional/model-source folder explains importing a copy of the supplied GLB; the private Blender master is not distributed. Changing the model can invalidate its surface charts, so keep this walkthrough on the supplied GLB and matching metadata. The notes link to the integration maintainer's instructions if you choose the Blender route.
