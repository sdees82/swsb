# Optional model inspection

The public companion supplies starter/public/models/championship-ring.glb and matching starter/model-metadata JSON. The GLB has embedded material definitions and no external image dependencies. The private Blender master is not included: its file metadata contained local author paths. It remains in the author’s preserved local source and editorial backups.

The core walkthrough requires no Blender authoring. For an optional inspection, import a copy of the supplied GLB in Blender. Describe any proposed change in Markdown and direct the agent to work on a copy; inspect its result in Blender. No Blender authoring or export script is bundled. Blender MCP is optional and is neither bundled nor configured.

A changed GLB needs matching surface charts and version metadata. Recheck meshes, material names, bounds, outward text placement and browser behavior. Keep the core walkthrough on the supplied GLB and its matching metadata.
